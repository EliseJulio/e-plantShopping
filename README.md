# Paradise Nursery

Paradise Nursery is a plant shop application for discovering indoor plants and managing a shopping cart. Browse the catalog, add plants to your cart, adjust quantities, and review the order total before checkout.

## Run locally

```bash
npm install
npm run dev
```

## Project structure

- `src/App.jsx` — landing page and shop/cart navigation
- `src/components/AboutUs.jsx` — company information
- `src/components/ProductList.jsx` — searchable, filterable plant catalog
- `src/components/CartItem.jsx` — shopping cart and quantity controls
- `src/features/cart/CartSlice.jsx` — Redux cart reducers
