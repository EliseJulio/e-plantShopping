# e-plantShopping — Paradise Nursery

e-plantShopping is the Paradise Nursery plant shop application. Discover indoor plants across curated categories, add plants to a shopping cart, adjust quantities, and review the order total before checkout.

## Run locally

```bash
npm install
npm run dev
```

## Project structure

- `src/App.jsx` — landing page and shop/cart navigation
- `src/components/AboutUs.jsx` — company information
- `src/components/ProductList.jsx` — searchable, filterable plant catalog
- `src/components/CartItem.jsx` — shopping cart and quantity controls
- `src/features/cart/CartSlice.jsx` — Redux cart reducers
